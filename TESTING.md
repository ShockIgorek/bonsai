# Тестирование Bonsai

## Тестовый бэкап

Детерминированный набор данных и ожидаемые результаты — в `TEST_BACKUP.md`.

Статический JSON для ручного прохождения: `test-data/bonsai-test-backup.json`.

Генератор с относительными датами:

```bash
npm run test:backup
```

## Быстрый запуск

```bash
npm test        # юнит-тесты логики
npm run build   # проверка production-сборки
npm run dev     # приложение на компьютере
```

Телефон в той же Wi-Fi-сети:

```bash
npm run dev -- --host
```

Открой на телефоне адрес вида `http://192.168.x.x:5173`. Это отдельный origin: реальные данные установленного PWA на телефоне не затрагиваются. Для проверки PWA, service worker и обновлений нужен HTTPS-хостинг.

## Тестовые данные

Создай отдельное тестовое дерево или импортируй тестовый бэкап:

- циклическая задача с интервалом 1 минута;
- циклическая задача с интервалом 10 часов;
- циклическая задача с интервалом 24 часа;
- одноразовая задача;
- папка с двумя подзадачами;
- задача с фото;
- два настроения с разными приоритетами и скрытыми задачами.

## Чек-лист

### Задачи

- [ ] Создать одноразовую задачу: название, описание, фото, время, важность, сложность.
- [ ] Создать циклическую задачу с интервалом и проверить, что интервал сохранился.
- [ ] Отредактировать задачу: название, описание, тип, фото.
- [ ] Удалить задачу и проверить, что она исчезла из Тиндера, Навигации и Списка.
- [ ] Добавить подзадачу: родитель становится папкой и больше не показывается в Тиндере.

### Навигация и папки

- [ ] Перетащить задачу в папку.
- [ ] Перетащить задачу в корень.
- [ ] Открыть папку и вернуться по хлебным крошкам.
- [ ] Удалить папку с подтверждением и проверить, что дети тоже удалились.

### Тиндер

- [ ] Свайп влево переключает вперёд, вправо — назад.
- [ ] Стрелки клавиатуры работают на компьютере.
- [ ] Счётчик карточек совпадает с позицией.
- [ ] Скрытие задачи работает только для выбранного настроения.
- [ ] После выполнения карточка уходит в конец, показывается следующая.
- [ ] Последнее выполнение отображается в строке с типом и интервалом.

### Циклические задачи

- [ ] Выполнить задачу: открывается модалка сложности и времени.
- [ ] Время удобно менять большими кнопками «−» и «+», значение видно крупно.
- [ ] Кнопки «Отмена» и «Выполнить» стоят в столбик, «Выполнить» заметно крупнее.
- [ ] Сложность можно не оценивать отдельной галочкой, без кнопки «Пропустить».
- [ ] После выполнения появляется кулдаун, карточка становится прозрачной.
- [ ] Восстановленная задача получает бейдж «бонус +25% до <дата, время>» и подсветку карточки.
- [ ] Над таймером видно «восстановится дата, время · процент».
- [ ] По картинке идёт радиальный тёмный сектор по часовой стрелке.
- [ ] Таймер, дата и процент обновляются каждую секунду.
- [ ] Таймер восстановления стоит по центру картинки.
- [ ] Кнопка «Выполнить повторно» доступна на остывающей карточке.
- [ ] При повторном выполнении полоса серии заполняется по правилам 20-часового примера.
- [ ] Текущее ожидание не закрашивает сегменты на карточке.
- [ ] Шкала серии показывает завершённые циклы и начинается с первого заполненного сегмента.
- [ ] После 100–150% интервала действует бонус, после 150% он пропадает.
- [ ] Сложность считается по среднему последних 10 оценок, пропуск оценки не ломает среднее.

### Таймер

- [ ] Запустить таймер, свернуть приложение на 1–2 минуты, вернуться: время корректное.
- [ ] Заблокировать экран телефона, вернуться: время корректное.
- [ ] Пауза не увеличивает время.
- [ ] Продолжение после паузы корректно суммирует время.
- [ ] Запуск второго таймера ставит текущий на паузу, а не сбрасывает.
- [ ] Задачи с таймером на паузе поднимаются в начало колоды.
- [ ] Индикатор в шапке виден при любом таймере: сначала активный, иначе последний запущенный на паузе.
- [ ] У запущенного таймера в шапке есть пульсация; у паузы пульсации нет.
- [ ] Клик по индикатору ведёт к приоритетной задаче с таймером.
- [ ] Индикатор исчезает только когда таймеров нет вообще.
- [ ] Кнопка таймера на карточке меняет иконку: пауза при работе, play при паузе.
- [ ] В модалке таймера кнопки с иконками play / pause / stop.
- [ ] Сброс таймера требует подтверждения.
- [ ] При открытии модалки выполнения таймер фиксируется, а не продолжает считать время оценки.
- [ ] При отмене модалки таймер продолжает идти, если шёл до этого.
- [ ] Фактическое время попадает в лог и среднее последних 10 замеров.

### Одноразовые и архив

- [ ] Выполнить одноразовую задачу: появляется подтверждение.
- [ ] После подтверждения задача исчезает из дерева и появляется в архиве.
- [ ] В логе есть запись о выполнении.
- [ ] В архиве видны название, дата, настроение и путь.
- [ ] Восстановление возвращает задачу в исходную папку.
- [ ] Если папки нет, задача восстанавливается в корень.
- [ ] Удаление одной записи и очистка архива работают с подтверждением.
- [ ] Фото в архиве не хранятся, старые base64-фото вычищаются.

### Лог

- [ ] Записи отсортированы от новых к старым.
- [ ] Видны задача, дата/время, настроение, путь, сложность и время.
- [ ] Для пропущенной сложности и времени отображается «—».

### Настроения и приоритеты

- [ ] Переключение настроения меняет тему и порядок задач.
- [ ] Приоритеты одного настроения не меняют приоритеты другого.
- [ ] Калибровка задаёт вопросы «важнее», «быстрее», «сложнее»; ключевое слово выделено.
- [ ] Вопрос находится сверху, карточки ниже.
- [ ] На карточках видны время/сложность и бейдж «факт», «калибровка» или «оценка».
- [ ] Задачи с фактическими замерами не сравниваются друг с другом по этому измерению.
- [ ] Фактические значения не меняются после калибровки.
- [ ] Субъективные задачи интерполируются между фактическими; выход за диапазон прижимается к min/max.
- [ ] Прогресс показывает уровни «примерная / средняя / высокая» по 1/2/3 сравнениям.
- [ ] Скрытая задача не появляется в Тиндере выбранного настроения.
- [ ] На карточке настроения видна строка «Сначала: важные → короткие → простые» и блок «Сейчас в фокусе».
- [ ] Проценты и направления не перегружают карточку, детали открываются по «Настроить».
- [ ] После калибровки топ-3 и порядок Тиндера обновляются.
- [ ] Кнопка калибровки открывает экран «Калибровка».
- [ ] В Тиндере рядом с временем и сложностью видно, это факт, калибровка или оценка.
- [ ] Кнопка «Настроить» открывает экран весов и направлений.
- [ ] Пресеты «Баланс», «Отдых» и «Я машина» меняют проценты и направления.
- [ ] Ручные веса нормализуются при сохранении, карточка показывает новые проценты.
- [ ] Смена весов влияет на порядок Тиндера в этом настроении.
- [ ] «Сбросить» возвращает баланс, сохранение применяет изменения.

### Полный бэкап

- [ ] Скачать полный бэкап.
- [ ] Проверить, что в файле есть задачи, настроения, архив, лог и настройки.
- [ ] Импортировать бэкап на чистом origin.
- [ ] Проверить задачи, настроения, приоритеты, скрытые задачи, архив и лог.
- [ ] Проверить, что таймер и позиция Тиндера не переносятся.
- [ ] Проверить импорт битого файла: должно быть понятное сообщение об ошибке.

### PWA и обновление

- [ ] После HTTPS-деплоя приложение устанавливается как PWA.
- [ ] В бургер-меню видна строка `сборка ...`.
- [ ] После нового деплоя и полного перезапуска PWA версия обновляется.
- [ ] `sw.js` и `index.html` не залипают в кеше.

## Финальный gate перед миграцией

Миграцию реальной базы с телефона делать только после того, как:

- [ ] `npm test` проходит;
- [ ] `npm run build` проходит;
- [ ] чек-лист на компьютере пройден;
- [ ] ключевые сценарии проверены на телефоне;
- [ ] полный бэкап с телефона успешно импортирован на тестовый origin;
- [ ] старый сайт и старая PWA остаются доступными до проверки нового.
